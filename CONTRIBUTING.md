# Contributing

This project is open source, but not open to unsolicited contributions.

## Discussions

Start with a [discussion](https://github.marcelotryle.com/discussions): "Potential Issue" for possible bugs, "Ideas" for
feature requests, "Q&A" for questions. A maintainer decides whether it becomes an issue.

For bugs, include a minimal reproducer, the version you use, and the expected vs actual behaviour.

Do not post AI-generated content you have not reviewed yourself.

## Pull requests

Pull requests are by invitation. If a change is welcome, a maintainer will say so on the discussion or issue.
Unsolicited pull requests are closed without review.

## Security

Do not open public issues for vulnerabilities. See the [security policy](https://github.marcelotryle.com/security/policy).
